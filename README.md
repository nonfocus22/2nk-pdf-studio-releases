# 2NK PDF Studio — releases

Installers for **2NK PDF Studio**, the PDF viewer and editor used inside 2NK Group.

This repository holds releases only: the Windows installer (`.msi`) and `SHA256SUMS.txt` for each version.
There is no source code and there are no company documents here.

The app checks the latest release here (Help ▸ Check for updates, and at start unless turned off in Preferences),
offers a newer version, and installs it only if its SHA-256 matches `SHA256SUMS.txt`.
